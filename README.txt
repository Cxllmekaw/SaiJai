Sai Jai ♡ — Khun Jai Dee Edition
=================================

ไฟล์ในชุดนี้
- index.html
- style.css
- script.js
- favicon.svg
- khunjaidee-avatar.svg

ความสามารถหลัก
- บันทึกค่าความดัน SYS / DIA และชีพจร
- แสดงค่าล่าสุด ค่าเฉลี่ย และกราฟแนวโน้ม
- ประวัติย้อนหลัง พร้อมลบรายการ
- ส่งออกข้อมูลเป็น CSV
- Responsive รองรับมือถือและคอมพิวเตอร์
- AI ผู้ช่วย "คุณใจดี" สำหรับตอบคำถามทั่วไปเกี่ยวกับความดัน การดูแลตัวเองเบื้องต้น และวิธีใช้เว็บ

หมายเหตุสำคัญ
- ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์บนอุปกรณ์นี้
- ยังใช้ key เดิมชื่อ bloodPressure เพื่ออ่านข้อมูลจากโปรเจกต์เวอร์ชันก่อนหน้าได้
- AI คุณใจดีให้ข้อมูลทั่วไปเท่านั้น ไม่ใช่คำวินิจฉัยทางการแพทย์

วิธีใช้งาน
1) แตกไฟล์ ZIP
2) เปิด index.html ในเบราว์เซอร์ หรือใช้ Live Server ใน VS Code
3) เริ่มบันทึกข้อมูล หรือใช้ส่วน AI ผู้ช่วยได้ทันที
